# GoodHealth Pharmacy Website

A responsive static website built with HTML, CSS and JavaScript. No paid software is required.

## Included
- Responsive home page with mobile navigation
- Pharmacy services, health essentials, about and contact sections
- Contact enquiry form that opens the visitor's email app after you configure the pharmacy email
- Editable phone, address and email details
- Basic page title, description and favicon

## Before publishing
1. Open `script.js` in a text editor.
2. Replace the empty values in `PHARMACY` with the real pharmacy email, phone number and address.
3. Review the text and confirm all services and claims accurately describe the pharmacy.
4. Open `index.html` in a browser to preview the site.

## Publish free using Cloudflare Pages
1. Create a free account at https://dash.cloudflare.com/
2. Open **Workers & Pages** and choose to create a Pages project.
3. Choose **Upload assets / Direct Upload** (the wording may vary).
4. Upload the website files in this folder, or upload a ZIP if the interface accepts it.
5. Publish. Cloudflare provides a free address similar to `your-project.pages.dev`.
6. In the Pages project, open **Custom domains** if you later buy or already own a domain.

Alternative: use https://www.netlify.com/ and drag the site folder into its manual deploy area.

## Domain note
A free hosting address such as `goodhealth-pharmacy.pages.dev` may be available if the name is unused. A custom domain like `goodhealthpharmacy.com` normally costs money each year. Hosting is free on the options above, but domain-name availability is not guaranteed.

## Contact form note
The contact form is intentionally a simple mailto form. It does not store messages or send them through a server. For a form that works without the visitor's email app, connect a form provider and configure spam protection.

## Pharmacy compliance
This website is a general business-information template. Add only verified pharmacy details and ensure medicines, prescriptions, advertising and privacy practices comply with Ghanaian law and applicable Pharmacy Council / regulatory requirements. Do not publish patient information.
